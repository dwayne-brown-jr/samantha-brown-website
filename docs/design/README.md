# Design notes

The decisions behind the site's current look, from the October 2026 redesign.

- `DESIGN.md` — the visual system: colours, fonts, spacing, motion, and what each home section is for.
- `PRODUCT.md` — who the site is for, what it should get visitors to do, and what can't be claimed.

These were written for a static prototype, so their "Stack" lines don't apply. The live site is the React app in `src/`, and the design tokens now live in `src/home.css`.
